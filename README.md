# Maek Ha Poultry (CHICKEN NI DODONG)

A cute pink digital poultry e-commerce website featuring 12 chicken breeds.

## Features

- Home page with hero, featured chickens, age categories
- Shop page with search, filters, and sort
- Product detail pages
- Shopping cart with persistence
- Checkout (demo)
- About & Contact pages
- Responsive design

## Setup

1. Install dependencies:
`ash
npm install
`

2. Start dev server:
`ash
npm run dev
`

3. Build:
`ash
npm run build
`

## Adding Photos

Add chicken photos to public/images/chickens/ with the filenames specified in src/data/chickens.js.

## Editing Product Data

Edit src/data/chickens.js to update prices, stock, descriptions, etc.
